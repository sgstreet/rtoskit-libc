# Size: x86_64

Release build of `linux-x86_64`, measured with `tools/scripts/size-report` (PLAN D51,
`docs/research/size-measurement.md`). The figures are in `baseline-x86_64.json`;
`tools/scripts/size-report diff` compares a build with them. Each phase 2 step
records its reductions, and justifies any growth, in a section below.

x86_64 is measured for reference only. Its `unwind` column is `.eh_frame`, which the host compiler emits by default.
