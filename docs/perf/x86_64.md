# Benchmarks: x86_64

Core: x86-64 (the Phase 3 perf reference). Counts come from qemu-x86_64 with the plugin; cycles are `rdtsc` on this shared VM (fastest of 15, pinned) and move by ±40 % between runs, so they are context, not a gate.

Method: `docs/research/benchmarks.md` (PLAN D72). Regenerate the tables with
`tools/scripts/bench-runner [--build-type speed] markdown --board linux-x86_64 [--previous <rev> | --against <file>]`;
`docs/perf/baseline-x86_64.json` (size flavour) and `docs/perf/baseline-x86_64-speed.json` (speed flavour, PLAN D73)
hold every case, including the full string sweep.
